## Bug 修复：收信 Webhook 未触发
- 用户反馈收信未触发 Webhook。排查后修复 4 个问题：
  1. `setting-service.get()` 回显密钥打码后，前端保存时把 `******` 写回 D1，导致带鉴权的 Webhook/TG/Resend 调用失败；`set()` 现在遇到打码值保留数据库原值（覆盖 webhookSecret/tgBotToken/secretKey/S3/Resend tokens）。
  2. `webhook-service.sendEmail()` 原先把 HTTP 200 一律当成功，企微/钉钉业务错误被吞掉；现在解析 `errcode`/`StatusCode` 并按失败重试，日志带 host 与 emailId。
  3. 前端“格式说明”示例仍是旧版扁平 JSON，与实际发送的企业微信/钉钉 `msgtype: text` 格式不一致，已同步。
  4. 收信与站内发信两处 Webhook 分支增加状态日志，便于在 Workers 日志确认是否走到发送。
- 验证：3 个后端 JS 文件 `node --check` 通过；`vite build --mode release` 构建成功。
- 仍需用户确认运行侧配置：Webhook 开关（OPEN=0）、转发规则 ruleType、URL 必须为公网域名，以及部署后查看 Workers 日志。
